# 美股芯片监控：第一阶段数据契约

第一阶段复用现有注册表、快照和页面查询体系，新增纯函数基础层，不保存任何 API 密钥。

- 行情源优先级：`tx_us_quote` → `em_global_quote` → `sina_us_quote`。每个源有独立超时、重试、熔断阈值和恢复窗口。
- 时间：采集、接收和落盘时间统一为 UTC ISO 8601；美股交易时段按 `America/New_York`（含夏令时）解释，交易日由日历和节假日集合决定。
- 质量：按主体、字段、时点、来源去重；检测缺失、延迟、异常值和跨源价差，输出 0–100 分、最大延迟和明确标志。
- 缓存：沿用 `snapshot.ts` 的内存/磁盘快照与端点最大缓存年龄；新数据使用序列号和接收时间做增量合并，失败和空结果不覆盖好快照。
- 监控目录：2Y、10Y、DXY、NQ、SOX、SOXX、SMH、VIX、NVDA、AVGO、AMD、TSM、MU；AI CapEx 字段与 SEC、财报日历、新闻事件入口已登记。

真实实时性仍取决于上游授权和源自身延迟。当前零凭证行情入口可用于开发与降级；SEC 入口需要 `VRA_SEC_CONTACT`（包含可联系的应用名/邮箱 User-Agent），生产级低延迟行情建议下一阶段接入具备明确 SLA 的授权源。
